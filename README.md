# Analysis and Implementation of LNN-Based Temporal Decorrelation for Neural Signal Compression

Project Work: Decorrelation engine with LNN for neural signal compression (Python Version)

-- Objective --

The action potential signal plays a crucial role in the realm of neuroprosthetics. Cutting-edge neural implants are capable of recording data from a multitude of electrodes within the brain, ranging from a few to hundreds. However, this vast amount of data transmission poses challenges, particularly in terms of power consumption and bandwidth. To address this, an on-chip compression engine is highly recommended, with a particular emphasis on lossless compression.
The initial stage of this compression process involves temporal decorrelation, which aims to mitigate data redundancy over time. While differential pulse code modulation (DPCM) has been extensively researched and has demonstrated impressive results in this regard, there remains room for enhancement in decorrelation performance.
This project seeks to delve into the realm of linear neural network- (LNNT-) based temporal decorrelation, with the overarching goal of refining decorrelation performance in software and implementing it efficiently in hardware.

The thesis consists of the following tasks:
1. Study on the one-dimensional signal decorrelation and compression algorithms.
2. Software implementation, documentation and quantization of the LNNT-based temporal decorrelation. Additionally, compare it to DPCM. 
3. Synthesizable Hardware implementation of the LNNT-based decorrelation in RTL.
4. Verification of the hardware implementation against the software reference.

The Student thesis work is to be written in English.
